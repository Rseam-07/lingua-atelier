# 第一次使用

需要 Obsidian 1.11.4 或更新版本。当前为 GitHub 公开测试版，尚未上架社区目录。

## 安装一次

- 已装 BRAT：添加公开仓库 `Rseam-07/lingua-atelier`，安装并启用 Lingua Atelier。
- 没有 BRAT：电脑解压分享包，运行对应的 `Install-*`，选择仓库；也可把 `lingua-atelier` 文件夹放入仓库 `.obsidian/plugins/`。再在 Obsidian 第三方插件中启用。
- 手机可通过 BRAT 安装同一份插件，无需在手机运行脚本、Python 或终端。

## 首次打开：选、下载、检查

首次启用会显示“快速设置”；以后从工作台右上角或命令面板打开。

1. **语音识别**：选择“当前设备本地”，在 Whisper Tiny / Base / Small 中选一个，再点击“下载 / 修复”。桌面也可选 Qwen3-ASR 增强模式，点击按钮安装环境和模型。选择在线识别时，无需下载语音模型，但要填自己的百炼密钥并确认发送录音。
2. **翻译、笔记与导图**：选择本地文字模型并点击下载，或选择自己的在线 API。已有 Ollama 可保留。下载状态与首次加载检查成功后再继续。
3. 点击 **“检查并完成”**，阅读出现的使用提示。先试录一分钟已知内容，确认收音、字幕速度、翻译和保存。

下载只在你点击后开始，不会随插件启用自动下载。下载失败后再次点击会复用已完成且校验通过的文件。以后使用通常不需要重新下载或手动启动服务。

## 怎么选

| 选项 | 下载量约 | 适合什么 |
| --- | --- | --- |
| 本地 Whisper Tiny | 42 MB | 安静短句、先检查设备是否可运行；嘈杂课堂误听较多 |
| 本地 Whisper Base | 77 MB | 手机轻量模式的起点；不保证实时速度 |
| 本地 Whisper Small | 241 MB | 较强设备、课后导入；更占内存、更慢 |
| 桌面 Qwen3-ASR 1.7B | 2.5 / 4.7 GB + 依赖 | Mac / Windows 桌面增强识别；不在手机安装 Python |
| 本地 Qwen2.5 0.5B 文字 | 496 MB | 本地轻量体验；法语翻译与结构化整理可能有明显错误 |
| 本地 Qwen2.5 1.5B 文字 | 约 1.5 GB | 更强设备；仍须检查翻译与整理，不保证手机加载成功 |
| 在线识别 / 在线文字 | 无模型下载 | 使用者自己的 API，需要网络，可能按量收费 |

语音与文字可自由组合，例如“本地识别 + 在线翻译”。在线百炼识别与百炼文字可以共用同一地域的密钥；DeepSeek 只处理文字，不能代替语音识别。插件不附带任何共享密钥或免费额度。

## 开始录音后

1. 输入课程名称，选择主要语言。英语课程选英语，法语课程选法语，中法切换可选自动。
2. 点“开始录音”，允许 Obsidian 使用麦克风。字幕按约 4–10 秒音频分段到达，并非逐字同步。
3. “课堂笔记”通常积累约 30 秒内容后更新；“双语字幕”看原文和中文；“思维导图”可缩放、折叠。
4. 点“结束录音”，等剩余识别和整理完成。录音、字幕与 Markdown 留在仓库 `Lingua/`。
5. 右上角“使用提示”可以随时重新查看。已有录音用“导入音频”；旧课程用“历史笔记”；“归档笔记”整理文件位置；“重新整理”更新当前内容和导图。

## 手机本地模式

下载完成后可尝试在手机自身离线处理，不要求另一台电脑。推理代码已随插件打包。模型保存在本插件配置目录的 `local-models/`；如使用仓库同步，请留意模型文件的排除规则。

手机本地推理仍是测试功能：系统、内存、WebAssembly 和麦克风能力会影响是否能用。轻量语音建议至少 4 GB 设备内存，0.5B 文字建议至少 6 GB，大模型更高；这些是建议而不是兼容保证。录音请保持 Obsidian 前台，不保证锁屏或后台持续录音。先用一分钟验证；不适合的设备可选在线模式，或系统录音后导入。

## 遇到问题

- **模型还没准备好**：回到快速设置，先下载两个所需的本地模型，等加载检查通过；在线模式填写自己的对应密钥。
- **下载失败**：检查网络和空间，重试会复用已完成文件；Hugging Face 在部分网络环境可能不可达。
- **处理越来越慢**：看底部待识别数量；换小模型、改用在线文字服务，或课后导入。小模型快不代表听得更准。
- **没有字幕**：检查麦克风权限、输入设备与收音；先说一句已知内容。手机不支持实时输入时用系统录音再导入。
- **有错字 / 翻译错 / 整理失败**：点击时间回听，失败可重试。轻量文字模型可能无法完成复杂 JSON 整理，可选择更大的文字模型或在线服务。不会静默上传到在线服务。
- **找不到旧笔记**：打开“历史笔记”或 `Lingua/` 文件夹，原始音频始终保留。
- **升级**：先结束并保存录音，再用 BRAT 或安装包升级；旧设置、密钥与笔记保留。

## 高级方式：连接自有电脑

此方式仍保留，但不是手机使用的必要步骤。

电脑安装桌面组件并运行 `Share-to-phone-*`。手机高级设置选择 Qwen 服务，填写电脑局域网 / VPN 地址 `http://电脑IP:8183` 与电脑本地 `connection-token.txt` 中的密钥。手机 localhost 指手机自身。服务需要双方网络可达；公网连接应自行配置 HTTPS。不要把连接密钥放入 URL、笔记或公开反馈。
