# 朋友第一次安装

这是公开测试版。Mac Apple Silicon 是目前主要验证环境；Windows 与移动端仍需真机验收。

## 电脑

1. 先安装 Obsidian 并创建／打开一个仓库，确认版本至少为 1.11.4。
2. 解压分享包。结束所有录音并退出 Obsidian，运行对应的 `Install-*` 脚本，选择仓库。PowerShell 如按系统策略禁止运行脚本，可按下方手动安装插件，不需要修改系统全局执行策略。
3. 手动方式：把 `lingua-atelier` 文件夹放到仓库 `.obsidian/plugins/` 中；自定义配置目录时使用自己的配置目录。重开 Obsidian 并启用本插件。
4. 本地识别：运行 `desktop-service/Setup-*`，首次安装需联网和数 GB 空间。下载失败可以重试，模型文件会续传。Windows x64 会按硬件选择 PyTorch 后端，无 NVIDIA GPU 时可能较慢。
5. 文字翻译与整理：选择本地 Ollama 并安装 `qwen2.5:3b`，或使用自己的文字 API。API Key 填在插件设置中；每位使用者独立提供。
6. 在设置中检测并启动服务；选择麦克风与本课语言：英语／法语／中文；中法切换课程可选“中法自动识别”。新安装默认启用中法双路；不适用时可关闭。
7. 点击开始录音，结束后检查字幕、要点和导图。先用一分钟的已知内容检查识别及保存，再投入整节课程。

原始音频与自动稿都保存在 `Lingua/`。Mac 安装器不修改其他插件，不切换主题。`appearance/lingua-paper.css` 是可选配色；如需使用，自行复制到 `.obsidian/snippets/` 并启用。

## 手机 / 平板

1. 安装同一个插件文件夹，或公开发布后使用 BRAT 安装。插件没有 Node 或 Electron 加载依赖。
2. 在电脑安装识别组件，然后运行 `desktop-service/Share-to-phone-*`，保持电脑和手机网络可达。
3. 在手机的 Qwen 服务地址中填写 `http://电脑的局域网IP:8183`，将电脑本地 `connection-token.txt` 的内容填入“识别服务连接密钥”。不要把连接密钥放在 URL、笔记或公开问题反馈里。
4. 手机文字处理选自己的兼容 API（例如 DeepSeek），或已由你安全配置的文字服务。默认 Ollama 的 localhost 不能连接到电脑。
5. 阅读、Markdown、字幕与导图可在同一个仓库中使用；仓库同步由用户自行设置。本插件不会自动把朋友的笔记合并，也不提供多人同时编辑服务。
6. 实时录音请保持 Obsidian 在前台。若设备不开放麦克风或 AudioWorklet，使用系统录音后“导入音频”。锁屏、后台、蓝牙切换及 iOS 局域网权限都需要真机验证。

识别共享默认使用可信局域网／VPN；公网连接须自行配置 HTTPS，勿将裸 HTTP 端口直接暴露公网。共享服务处理来自已持有连接密钥设备的音频；不要把自己的电脑当成无限并发的公共服务器。

## 常见问题

- **找不到识别环境**：先运行桌面识别组件安装器，再在插件设置中检查 Python 与模型目录。已有环境可直接填写绝对路径。
- **手机服务不通**：localhost 是手机本身。检查 IP、8183 端口、电脑防火墙和系统本地网络权限；不要为排错关闭整个防火墙。
- **翻译／整理没有开始**：识别服务和文字模型都需要就绪，检测连接会分别显示状态。DeepSeek 是文字处理接口，不承担本插件的语音识别。
- **没有字幕或有错字**：先看麦克风输入与波形；回听原音，不能用更流畅的自动稿当准确率。录音保留，可重试。
- **系统音频无法启动**：当前只有 Mac 原生组件；需要系统录音权限。二进制尚未公证，可从源码构建；其他平台先用麦克风／系统音频输入设备或导入音频。
- **升级**：结束录音后安装新版。手动安装器备份旧的三个文件，保留 `data.json` 与 SecretStorage；无需复制朋友的配置。
- **卸载**：在 Obsidian 卸载插件。笔记仍是普通 Markdown；桌面模型和 Python 环境独立保存，如不再需要可自行删除 `Lingua Atelier` 组件目录。
